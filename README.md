# 🧮 AI Calculator

Калькулятор с ИИ: простые примеры считает сам, сложные спрашивает у нейросети.

## Установка

pip install -r requirements.txt

Создай файл .env и вставь туда:
GROQ_API_KEY=твой_ключ_с_console.groq.com

## Запуск

python main.py

## Пример работы

Ты: 2 + 2 * 10
🤖 Калькулятор: 22

Ты: корень из 144?
🤖 ИИ: 12
